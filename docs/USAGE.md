# 使用指南

## 获取文字稿

1. 确认设置中 `yt-dlp`、`ffmpeg`、`ffprobe`、`whisper-cli` 和 `node` 可用；默认模型已下载，或已选择自己的模型文件。
2. 输入网址或导入本地媒体。网址任务只处理单个视频，不自动展开播放列表。
3. 选择实际原声语言。中文/英文会优先匹配相应字幕；自动检测无法确定字幕原声语言时转写音轨。字幕本身可能包含双语，不代表本软件执行了翻译。
4. 点击生成。长视频的下载、模型加载和转写可能耗时较久，可展开处理日志查看进展。
5. 等待完成后预览、搜索、复制或导出。

## 导出格式

| 格式 | 内容 |
|---|---|
| 纯文字 TXT | 每段正文，无时间戳 |
| 带时间戳 TXT | 每段的起止时间和正文 |
| SRT | 带毫秒时间戳的标准字幕 |
| JSON | 标题、来源、生成方法和结构化分段 |

GUI 的保存面板由用户选择输出位置。MCP 默认不覆盖指定位置的已有文件；需要覆盖时必须明确传入 `overwrite=true`。

## 代理与错误排查

- 应用按任务源网址读取 macOS 系统代理，支持 HTTP/HTTPS/SOCKS 解析和例外规则。不会让旧终端代理环境变量覆盖该决定。
- 当前任务使用开始时选定的出口。改系统代理后请新建任务；未声明对每个 CDN URL 动态重算 PAC。
- 日志出现登录或机器人验证时，不要不断重试同样请求。当前没有 Cookies 登录配置界面。
- 若模型缺失，运行下载脚本或在设置选择正确 `.bin` 文件；模型格式不是任意 Hugging Face 权重。
- 初次运行新路径的工具可能较慢。错误日志能帮助区分工具启动、网络、媒体处理与模型问题。
- 安装脚本的 `curl` 使用其环境中的代理变量；如仅启用了系统代理而终端下载失败，可为该命令设置你自己的 `HTTPS_PROXY`。应用内部的代理读取与安装脚本是不同路径。

## 本地数据

默认位于个人资源库 `Application Support/VideoScribe`：

- `history.json`：GUI 完成记录。
- `jobs/`：异步任务状态、日志、媒体与结果。
- `models/`：默认本地模型。

不要把这些目录上传到公开仓库。导入本地媒体时只引用原文件；取消不会删除原媒体。保留视频会占用磁盘空间，删除任务文件前请确认没有正在运行的 worker。

关闭 GUI 或 MCP 后 worker 继续。崩溃或重启后会识别为 `interrupted`，再通过 `retry_job` 创建新任务。GUI 会载入外部已完成结果；进行中的外部任务应通过 MCP 查询/取消，当前没有完整 GUI 队列管理面板。
